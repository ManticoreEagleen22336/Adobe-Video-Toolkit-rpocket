# Troubleshooting

<details><summary>Blocked flag survived the download</summary>

Tick Unblock in Properties, then give `setup` a fresh start.
</details>

<details><summary>You were still inside the compressed file</summary>

Unpacking has to happen before a click can reach a real file.
</details>

<details><summary>SmartScreen warns on first launch</summary>

This warning appears because the file is unsigned. You can choose to proceed by selecting 'Run anyway'.
</details>

<details><summary>Antivirus put `setup` in quarantine</summary>

Bring the held copy out of quarantine, then start `setup` from the folder that was extracted.
</details>

<details><summary>Extract the zip file first</summary>

To run the program, make sure to extract the contents of the zip archive. After extraction, double-click on the `setup` file located in the folder.
</details>
